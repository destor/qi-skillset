# Course

Information about the user's own course: the order in which it covers the material, what it leaves out, and the notation its lectures use. It is filled in by the user before the skills are built. A section that still reads "Not filled in." holds nothing; if all of them do, ignore this file. Course information the user pastes in a session is used the same way and takes precedence over this file.
